# 📊 E-Commerce Sales Analysis

## 📌 Project Overview
Analysis of e-commerce sales data using Microsoft Excel to identify 
sales trends, top-performing categories, and regional performance.

## 🛠️ Tools Used
- Microsoft Excel (Pivot Table, SUMIF, COUNTIF, Dashboard)

## 📈 Key Insights
1. Jakarta is the highest revenue city (Rp 5,415,000)
2. Fashion category outperforms Electronics (Rp 6,920,000 vs Rp 5,880,000)
3. Total revenue from 20 transactions reached Rp 12,800,000
4. Monitor is the highest single transaction product (Rp 1,850,000)
